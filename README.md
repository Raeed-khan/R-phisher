##

### Installation

- Just, Clone this repository -

```

git clone --depth=1 [https://github.com/Raeed-khan/R-phisher.git](https://www.google.com/search?q=https://github.com/Raeed-khan/R-phisher.git)

```

- Now go to cloned directory and run `R-phisher.sh` -

```

$ cd R-phisher
$ bash R-phisher.sh

```

- On first launch, It'll install the dependencies and that's it. ***R-phisher*** is installed.

##

### Installation (Termux)
You can easily install R-phisher in Termux by using tur-repo

```

$ pkg install tur-repo
$ pkg install R-phisher
$ R-phisher

```

***Termux discourages hacking*** .. So never discuss anything related to *R-phisher* in any of the termux discussion groups. For more check : [wiki](https://wiki.termux.com/wiki/Hacking)

### Installation via ".deb" file

- Download `.deb` files from the [**Latest Release**](https://github.com/Raeed-khan/R-phisher/releases/latest)
- If you are using ***termux*** then download the `*_termux.deb`

- Install the `.deb` file by executing

```

apt install 

```
Or

```

$ dpkg -i 
$ apt install -f

```

##

### Run on Docker

- Docker Image Mirror:
- **DockerHub** : 
  ```
  docker pull raeedkhan/R-phisher
  ```
- **GHCR** : 
  ```
  docker pull ghcr.io/raeed-khan/r-phisher:latest
  ```

- By using the wrapper script [**run-docker.sh**](https://raw.githubusercontent.com/Raeed-khan/R-phisher/master/run-docker.sh)


```

$ curl -LO [https://raw.githubusercontent.com/Raeed-khan/R-phisher/master/run-docker.sh]()
$ bash run-docker.sh

```
- Temporary Container


```

docker run --rm -ti raeedkhan/R-phisher

```
- Remember to mount the `auth` directory.
